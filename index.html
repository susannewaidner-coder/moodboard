Kurzanleitung: Client-ID erstellen
  1. In der Google Cloud Console ein kostenloses Projekt anlegen.
  2. Unter APIs & Dienste → Bibliothek die Google Drive API aktivieren.
  3. Unter OAuth-Zustimmungsbildschirm „Extern“ wählen und deine eigene Gmail-Adresse als Testnutzer eintragen.
  4. Unter Anmeldedaten → OAuth-Client-ID erstellen „Webanwendung“ wählen und deine GitHub-Pages-URL (z. B. https://deinname.github.io) bei Autorisierte JavaScript-Ursprünge eintragen.
